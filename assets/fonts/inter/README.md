# Inter 4.1

Unmodified official static Inter Regular and Bold from:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

SIL OFL 1.1 included. metrics.json contains advance widths derived from the Bold
font for conservative line fitting. This is a visual approximation of the baked
reference captions; the MP4 does not identify its original font family.

Progressive text positioning uses `assEmHeight: 2478` (hhea ascent1984 minus
descent−494, unitsPerEm2048) for libass placement. These are metrics from the
bundled Inter Bold file; they do not identify the reference font. Width fitting
keeps its conservative em-based limit. Words stay shaped as whole prefixes;
only keyword entrances use separately positioned glyphs.
