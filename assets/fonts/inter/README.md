# Inter 4.1

Unmodified official static Inter Regular and Bold from:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

SIL OFL 1.1 included. metrics.json contains advance widths derived from the Bold
font for conservative line fitting. This is a visual approximation of the baked
reference captions; the MP4 does not identify its original font family.
