# Fase 9 · E2E + primer vídeo real · acceptance foundation

Pretrabajo de criterio de aceptación. No afirma que el E2E exista todavía.

## Gate técnico V1
El manifest exige:
- fuente intacta;
- transcript;
- captions;
- visión;
- Reframe Plan;
- plantilla;
- Director Plan;
- preview;
- MP4 final.

Checks obligatorios:
- source-intact;
- captions-human-reviewed;
- face-track-stable;
- safe-zones-ok;
- preview-reviewed;
- final-decodes;
- audio-present;
- no-secret-leak.

## Gate cualitativo
V1 sólo se acepta si Carlos considera que no hay cambios mayores y quedan como máximo
2–3 retoques menores. Frase de criterio: «Cambiaría dos o tres cosas, pero el vídeo
prácticamente está.»

## Prueba final real
Carlos sube un vídeo real → selecciona plantilla → sistema procesa → preview → ajustes →
MP4 final. No vale sustituir esta prueba por fixtures ni dry-runs.

## Pendiente
Todo el E2E real, integración y revisión humana. Este foundation sólo evita que al llegar
a Fase 9 se rebaje o se interprete ambiguamente el criterio de terminado.
